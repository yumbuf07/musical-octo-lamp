# 纸感笔记（Paper Notes）

一个更完整的笔记 Web 小工具：

- 邮箱注册 / 登录（本地浏览器存储）。
- 自动记录笔记日期。
- 笔记索引（按时间倒序）与按日期搜索。
- 自动保存（输入后约 1 秒自动持久化）。
- 将缩进文本一键转换为思维导图。
- 主题设置（白色、黑色、粉色、浅绿色、浅蓝色、纸张米白）。
- 导出当前笔记为 PNG 图片。
- 图片 OCR 识别文字并追加保存（依赖网络加载 `tesseract.js`）。

## 快速开始

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 笔记转思维导图规则

- 每行是一个节点。
- 通过空格或 Tab 的缩进表示层级关系。
- 标题会作为思维导图根节点。
